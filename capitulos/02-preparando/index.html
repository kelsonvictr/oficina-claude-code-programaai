Preparando o

Vinte minutos de paciência agora, meses de trabalho automatizado depois. Passo a passo para Windows e Mac — sem pré-requisitos escondidos, sem "instale antes o negócio X".

💻 windows e mac 🚪 2 portas de entrada 🛟 plano B para cada tropeço
🪪
Passo 0: a conta (a única parte que custa dinheiro)
Resolva isso primeiro — de preferência em casa, antes da oficina.

Como vimos no capítulo 1, o Claude Code precisa de uma assinatura paga (o plano Pro, de ~US$ 20/mês, resolve). A boa notícia: criar a conta e assinar é igual a assinar qualquer streaming — e-mail, senha, cartão, pronto.

  1. Abra claude.ai no navegador e crie sua conta (pode entrar com a conta Google, é o caminho mais rápido).
  2. Confirme seu e-mail, se for pedido.
  3. Vá em planos (ou acesse claude.com/pricing) e assine o Pro. Guarde o e-mail e a senha usados — você vai precisar deles no primeiro login.
💡
Já usa o Claude no navegador com plano pago? Então este passo já está feito: é a mesma conta. Pule direto para as portas de entrada.
🚪
Duas portas para o mesmo lugar
O motor é idêntico. O que muda é a maçaneta.

Existem dois jeitos de usar o Claude Code no seu computador. Os dois funcionam igualmente bem — escolha pela sua personalidade:

recomendada para começar 🖥️

Porta A: o aplicativo

Um programa normal, com janela, botões e menus — como o Word ou o Spotify. Você baixa, instala com dois cliques e conversa numa interface visual. Se a palavra "terminal" te dá arrepio, entre por aqui.

⌨️

Porta B: o terminal

A janela "de hacker" — que, spoiler, é só uma caixa de conversa sem botões. Instala com um único comando copiado e colado. Quem quer a experiência raiz (ou vai usar o material desta oficina ao pé da letra) entra por aqui.

Carro automático × manual

O aplicativo é o câmbio automático: mais confortável no começo. O terminal é o manual: o mesmo carro, um pouco mais de controle. Você pode trocar de porta a qualquer momento — as configurações e conversas são as mesmas nos dois.

🖥️
Porta A: instalando o aplicativo
Baixar, clicar, esperar. Você já fez isso mil vezes na vida.
🧩
No Windows, o aplicativo precisa de um ajudante: o Git. É o único programa extra desta oficina — e é exigência do app, não capricho nosso: sem ele, o Claude Code não consegue trabalhar nas pastas do seu computador. Você nunca vai usar o Git diretamente; ele fica nos bastidores, como o motor de impressão que o Word usa sem te perguntar nada. Por isso ele é o passo 1 aqui embaixo.
  1. Instale o Git primeiro (botão cinza abaixo). No instalador, pode clicar em Next até o fim e depois em Install: as opções padrão servem perfeitamente. Ele fala inglês e mostra várias telas — ignore os detalhes, é bastidor puro.
  2. Baixe o Claude (botão coral abaixo) e abra o arquivo baixado. Siga o instalador aceitando as opções padrão.
  3. Ao abrir pela primeira vez, o aplicativo mostra abas no topo. Clique na aba Code — é onde a nossa oficina inteira acontece.

🧩 1º · Instalar o Git (obrigatório no Windows) ⬇️ 2º · Baixar o aplicativo Claude

🎁
Consolo: esse ajudante chato tem um presente escondido. É ele que, lá no capítulo final, vira a sua máquina do tempo — o "ponto de restauração" que desfaz qualquer estrago numa pasta. Você já vai chegar lá com metade do caminho andado.
  1. Baixe o instalador clicando no botão abaixo (o download começa sozinho).
  2. Abra o arquivo .dmg baixado e arraste o ícone do Claude para a pasta Aplicativos, como o macOS sugere na janelinha.
  3. Abra o Claude pela pasta Aplicativos (na primeira vez, o Mac pergunta se confia no app — confirme). Nas abas do topo, clique em Code — é onde a nossa oficina inteira acontece.

⬇️ Baixar o aplicativo para Mac

🧩
Sorte sua: o Mac já vem preparado. O aplicativo precisa de um ajudante de bastidores chamado Git, e a maioria dos Macs já o tem instalado de fábrica. Se por acaso aparecer uma janelinha do sistema oferecendo instalar "ferramentas de linha de comando", é exatamente isso — clique em Instalar e espere terminar. (Colegas de Windows precisam instalar na mão; você não.)
🧭
As três abas do aplicativo: Chat é o Claude comum de conversa; Cowork é um modo avançado (ignore por ora); Code é o nosso — o assistente que mexe nos seus arquivos. Se a tela parecer diferente do material, confira primeiro se você está na aba certa.

Instalou? Ótimo — pule direto para o primeiro login (a Porta B é alternativa, não etapa).

⌨️
Porta B: instalando pelo terminal
Um comando. Literalmente um. E você ainda ganha uma história para contar.
MITO

"Terminal é coisa de programador, vou quebrar o computador."

NA REAL

O terminal é uma caixa de conversa com o computador — o WhatsApp sem os botões. Você digita, ele responde. Colar um comando ali não é mais perigoso que clicar num instalador; a diferença é só a estética.

  1. Abra o PowerShell: aperte a tecla Windows, digite powershell e aperte Enter. Vai abrir uma janela azul (ou preta) com texto — é ela.
  2. Copie o comando abaixo (botão 📋), clique na janela do PowerShell, cole com Ctrl+V e aperte Enter.
  3. Aguarde o texto parar de rolar (menos de um minuto). Quando aparecer a mensagem de sucesso, feche o PowerShell e abra de novo — isso "apresenta" o programa novo ao Windows.
⌨️ Comando pronto — cole no PowerShell 
irm https://claude.ai/install.ps1 | iex
O que ele faz: baixa o instalador oficial do site da Anthropic e o executa. É o mesmo que baixar e dar dois cliques — em versão texto.
  1. Abra o Terminal: aperte Cmd + espaço, digite terminal e aperte Enter. Vai abrir uma janela branca (ou preta) com texto — é ela.
  2. Copie o comando abaixo (botão 📋), clique na janela do Terminal, cole com Cmd+V e aperte Enter.
  3. Aguarde o texto parar de rolar (menos de um minuto). Quando aparecer a mensagem de sucesso, feche o Terminal e abra de novo — isso "apresenta" o programa novo ao Mac.
⌨️ Comando pronto — cole no Terminal 
curl -fsSL https://claude.ai/install.sh | bash
O que ele faz: baixa o instalador oficial do site da Anthropic e o executa. É o mesmo que baixar e dar dois cliques — em versão texto.
⚠️
Regra de ouro dos comandos colados: só cole comandos de fontes em que você confia — este veio da documentação oficial da Anthropic. É como remédio: a receita importa tanto quanto o comprimido.
🎉
Nada de Node, nada de Python — o instalador oficial é autossuficiente, apesar do que dizem tutoriais antigos. E o Git? Aqui na Porta B ele é opcional: sem ele, o Claude Code simplesmente usa o PowerShell para rodar os comandos (para tudo o que fazemos nesta oficina, dá no mesmo). Quem entra pela Porta A no Windows precisa dele — é a diferença entre as duas portas.
⏰
Mesmo assim, vale instalar o Git um dia. Não pela Porta B, mas porque é ele que vira a máquina do tempo do capítulo final (o "ponto de restauração" que desfaz estragos numa pasta). Você pode deixar para depois — e pedir ao próprio Claude que ele instala e configura para você.
🔑
O primeiro login: apresentando você a ele
Acontece uma vez só. Depois ele lembra de você.

Instalado (por qualquer porta), o Claude Code precisa saber quem você é — afinal, é a sua assinatura que ele vai usar. O fluxo é o mesmo nos dois caminhos:

  1. Abra o Claude Code. No aplicativo: abra o app e clique na aba Code. No terminal: digite claude e aperte Enter.
  2. Ele avisa que precisa de login e abre o seu navegador sozinho na página da Anthropic.
  3. No navegador, entre com a conta que você criou no Passo 0 (a mesma do claude.ai).
  4. O navegador confirma e manda você de volta. Na janela do Claude Code aparece: Login successful. Pronto — vocês se conhecem.
🖥️ o que vai aparecer na sua tela (terminal)
> claude Bem-vindo ao Claude Code! Abrindo o navegador para você entrar na sua conta… (o navegador abre, você faz login, e a janela continua:) Login successful. Tudo certo!
🔁
Isso não vai se repetir. O login fica guardado com segurança no seu computador. Amanhã, você abre o Claude Code e ele já sabe quem você é.
🛟
Deu errado? Respira — está tudo previsto aqui
Os quatro tropeços clássicos e a saída de cada um.
🧩 O aplicativo reclamou que falta o Git (Windows) ▼

É o erro nº 1 de quem entra pela Porta A no Windows — e a mensagem costuma vir em inglês, falando em "Git is required". Não é defeito do seu computador nem erro seu: o app realmente exige esse ajudante para trabalhar nas pastas locais.

Solução: instale pelo site oficial (git-scm.com/downloads/win), clicando em Next até o fim — as opções padrão servem. Depois feche o aplicativo Claude por completo e abra de novo: só assim ele percebe que o ajudante chegou.

Não quer instalar agora? Então entre pela Porta B (terminal), onde o Git é opcional. É o mesmo Claude Code, com outra maçaneta.

😵 Digitei claude e apareceu "comando não encontrado" ▼

Clássico — e inofensivo. O terminal que estava aberto ainda não conhece o programa recém-instalado. Solução: feche a janela do terminal e abra uma nova. Se persistir, rode o comando de instalação de novo (não faz mal rodar duas vezes) e reabra.

🌐 O navegador não abriu sozinho na hora do login ▼

A janela do Claude Code mostra um endereço (link) nesse caso — copie e cole no navegador você mesmo. Depois do login, se a volta automática também falhar, a página mostra um código de 6 caracteres: copie e cole na janela do Claude Code, onde ele diz "Paste code here". Mesmo destino, caminho manual.

🔒 "Esta conta não tem acesso" ou pedido de assinatura ▼

Sinal de que a conta é gratuita (ou você entrou com outro e-mail sem querer — acontece mais do que parece!). Confira no claude.ai, no seu perfil, se o plano Pro está ativo nesse e-mail. Ajustou? Rode o login de novo: digite /login na conversa do Claude Code.

🐢 Instalou, logou… e a primeira resposta está demorando ▼

Normal! Na primeira conversa em uma pasta, ele lê o terreno antes de responder — é o estagiário conhecendo a mesa nova. As respostas seguintes são bem mais rápidas. Só desconfie se passar de uns dois minutos sem nada acontecer (aí: feche e abra de novo, sem dó).

🆘
O plano C universal: descreva o erro para o Claude comum no navegador (claude.ai) — cole a mensagem de erro e pergunte o que fazer. Usar uma IA para instalar a outra é totalmente permitido. 😄
👋
O teste do "oi"
Trinta segundos para confirmar que está tudo vivo.

Antes de encerrar o capítulo, faça o teste completo. Abra o Claude Code (aba Code no aplicativo, ou claude no terminal) e digite:

✨ Seu primeiro prompt 
oi! você está funcionando? me responde em uma frase, em português.
🖥️ resposta esperada (a sua será parecida, não idêntica)
Estou funcionando perfeitamente — pronto para trabalhar com você!

Recebeu uma resposta em português? Então confira a lista da vitória:

  • Conta criada no claude.ai com plano Pro ativo
  • Windows + aplicativo? O Git instalado antes (no Mac já vem; no terminal é opcional)
  • Claude Code instalado (pelo aplicativo ou pelo terminal)
  • Login feito — apareceu o Login successful (ou o app entrou direto)
  • O teste do "oi" respondeu em português

O que ficou deste capítulo
O computador está pronto. Falta a primeira conversa de verdade.
  • O pré-requisito que custa dinheiro é um só: conta com plano pago. Sem Node, sem Python.
  • Git: obrigatório no aplicativo do Windows (é o "ajudante de bastidores"), já vem no Mac, opcional no terminal.
  • Duas portas, mesmo motor: aplicativo (visual, recomendado) e terminal (raiz).
  • Terminal não morde: é uma caixa de conversa sem botões.
  • Login acontece uma vez, pelo navegador, com a conta do claude.ai.
  • Deu erro? Fechar e reabrir resolve metade; a seção "Deu errado?" resolve o resto.
